# Local AI Chat 0.1.0

## Studio Next

В Studio при первом входе можно выбрать одного из шести персонажей или открыть обычный чат с музой. В «Карточки персонажей → Галерея студии» доступны оригиналы и создание личной редактируемой копии. В редакторе есть 14 портретов и загрузка своей картинки. В группе справа виден отвечающий участник. «Остановить» заменяет кнопку отправки во время генерации. Повтор и продолжение находятся под последним ответом. Язык меняется в настройках.

Поставка содержит исходный код и устанавливается локально по README. Модель и Node.js поставляются отдельно. При первой настройке задаётся собственный `INITIAL_ADMIN_PASSWORD`. Личные начальные персонажи и переписка в публичный комплект не включены. Лицензия исходного кода — MIT.

Интерфейс поддерживает русский и английский языки в одной поставке. Выбор доступен на экране входа и в настройках, сохраняется в браузере и не переводит пользовательские данные. Приложение предназначено для локального использования; аудит безопасности для публичного интернет-хостинга не проводился.

Запуск Windows через BAT: общая логика RU/EN, скрытый ввод пароля администратора, подготовка зависимостей и сборки, запуск только на loopback и открытие браузера после готовности. При отсутствии Node.js используется его отдельный официальный установщик. Отдельного BAT резервной копии нет; сохранены встроенный архив и копирование данных остановленного сервера.
