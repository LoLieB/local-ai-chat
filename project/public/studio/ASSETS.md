# Studio artwork

Original AI-generated static illustrations made for Local AI Chat. Luma, Rowan, Vesper, Ivo, Orrin and Mira are the six character editions. portrait-01 through portrait-14 are unassigned library portraits. Muse is a separate brand illustration. Each WebP has a smaller -sm companion. The geometric ribbon mark, wordmark, dark/light/monochrome SVGs and transparent PNG icons were drawn for this release. The interface uses installed system fonts. No remote image service is used at runtime.
