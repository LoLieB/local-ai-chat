# Local AI Chat 0.1.0

## Studio Next

Studio opens a gallery of six characters at first sign-in. Choose one or open a regular chat with the muse. Characters → Studio gallery lets you revisit an original or create an editable private copy. The editor includes 14 library portraits and image uploads. Group chats show the speaking character on the right. Stop replaces Send during generation. Retry and Continue appear beneath the latest reply. Change the interface language in Settings.

This source distribution is installed locally using the README. Node.js and the model are supplied separately. Set your own `INITIAL_ADMIN_PASSWORD` during initial setup. Personal starter characters and conversations are not included. The source code is licensed under MIT.

One distribution includes both English and Russian interfaces. The language can be selected on the sign-in screen and in Settings; the browser stores the choice. Interface language does not translate user data.

The application is intended for local use. Public internet hosting has not been separately security-audited. Back up your data and configuration before upgrading; the account export does not replace a complete server backup.

Windows click launchers: shared RU/EN setup and start flow, hidden admin password entry, dependency installation, build, loopback-only startup and browser readiness checks. Node.js is installed separately using its official installer if missing. No backup BAT is included; existing account backup and stopped-server file backup remain available.
